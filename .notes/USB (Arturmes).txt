При написании TWRP DT изначально
производил сборку на PC.
Сборка сыпала ошибками.
Поэтому обратился за помощью к
пользователю Arturmes.
Он помог сделать начальную
редактировку дерева.
Далее проводил сотни экспериментов,
чтобы довести до всё ума.
По совету пользователя Arturmes,
далее сборку проводил online.
Огромное спасибо Arturmes.

Информация относительно ADB,MTP,FASTBOOTD,
ADB Sideload,FASTBOOT.

В конечном итоге, к работе взят стоковый
файл init.recovery.common.rc.
При этом была обеспечена работа ADB,MTP,
ADB Sideload.
Но не работал FASTBOOTD и переключение
слотов A/B.
Путём экспериментов, на основе правок
пользователя Arturmes было установлено:
on boot
    start boot-hal-1-1
    start health-hal-2-1

    setprop sys.usb.configfs 1

    write /sys/block/mmcblk0boot0/force_ro 0
    write /sys/block/mmcblk0boot1/force_ro 0

Здесь:
1. start boot-hal-1-1
   start health-hal-2-1

   write /sys/block/mmcblk0boot0/force_ro 0
   write /sys/block/mmcblk0boot1/force_ro 0
Отвечает за возможность переключать
слоты A/B.
2. setprop sys.usb.configfs 1
Отвечает за установку и включение
конфигурации USB.

При соединении эти строк, выявлена 
работа всех перечисленных функций.

Важно отметить, что стоковый файл
init.recovery.common.rc имел запись
только данных строк:

on boot
    
    setprop sys.usb.configfs 1
    write /sys/block/mmcblk0boot0/force_ro 0
    write /sys/block/mmcblk0boot1/force_ro 0
